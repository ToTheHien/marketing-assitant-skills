Research and compile an industrial real estate market report.

## Report structure
1. **Executive summary**: 3-4 sentences with key takeaways
2. **Market overview**: Vacancy, absorption, avg asking rent, new supply
3. **Submarket analysis**: Break down by geography or property type
4. **Demand drivers**: E-commerce, nearshoring, cold storage, EV/battery, data centers
5. **Notable transactions**: Recent leases, sales, developments
6. **Outlook**: 6-12 month forecast with supporting data
7. **Implications for our portfolio/clients**

## Data handling
- Always cite sources (CBRE, JLL, Cushman, CoStar, or specify if estimated)
- If data is unavailable, say so — never fabricate statistics
- Compare YoY and QoQ trends where possible
- Include national context alongside local/submarket data

## Industrial-specific metrics
Track: vacancy rate, net absorption (SF), avg asking rent (NNN vs gross),
cap rates, new construction pipeline, months of supply,
tenant improvement allowances, concession trends
