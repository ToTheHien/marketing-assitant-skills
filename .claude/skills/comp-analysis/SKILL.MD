Conduct a competitive analysis for industrial real estate properties.

## Analysis framework
1. **Subject property profile**: Key specs, asking rent, location, unique features
2. **Comparable properties** (3-5 comps):
   - Address, size, clear height, year built
   - Asking rent (NNN basis), TI allowance
   - Days on market, occupancy status
3. **Feature comparison matrix**: Side-by-side on 8-10 key attributes
4. **Pricing analysis**: Subject vs avg comp rent, $/SF spread
5. **Competitive advantages**: What our property offers that comps don't
6. **Competitive threats**: Where comps outperform
7. **Pricing recommendation**: Suggested asking rent with justification
8. **Marketing differentiation strategy**: How to position against comps

## Key comparison attributes
Clear height, column spacing, dock doors (count + type),
truck court depth, parking ratio, power capacity,
ESFR/sprinkler rating, building age, LEED/sustainability features,
highway access (distance + routes), labor pool demographics

If specific comp data isn't available, note it and provide the analysis
framework the user can fill in.
